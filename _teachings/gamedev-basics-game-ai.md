## Course Overview

The course "Introduction to GameDev: Basics of Game AI" provides an introduction to the fundamental concepts and technologies of artificial intelligence in the game industry. Students will learn:

- Core architectures for creating intelligent behavior in game characters
- Navigation and pathfinding algorithms in game worlds
- Decision-making and action planning methods for NPCs
- Application of soft computing in game AI
- Practical implementation of AI systems in game engines

## Target Audience

This course is designed for students interested in:
- Computer game development
- Artificial intelligence
- Programming interactive systems
- Agent behavior modeling

## Prerequisites

- Basic programming knowledge (preferably C++ or Python)
- Understanding of algorithms and data structures fundamentals
- Familiarity with game engines (Unity, Unreal Engine) is desirable

## Technologies

The course utilizes:
- **Unreal Engine 4/5** - primary game engine for practical exercises
- **Python** - programming language for AI practicing
- **Behavior Designer** - tool for working with behavior trees

## Practical Projects

Students work on several practical labs and projects:

1. **Intelligent NPC** - creating a character with complex behavior
2. **Patrol System** - implementing group navigation
3. **Tactical AI** - developing AI for a tactical game
4. **Final Project** - independent development of an AI system

## Grading

- Assignments: 30%
- Lab Work: 20%
- Final Project: 30%
- Final exam: 20%
