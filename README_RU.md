# Академический Веб-сайт - Кирилл Абросимов

Это ваш академический веб-сайт, созданный с использованием Jekyll и темы al-folio, готовый к публикации на GitHub Pages.

## 🌐 URL Сайта

После публикации ваш сайт будет доступен по адресу: **https://lvodoleyl.github.io**

## 📋 Структура Сайта

Сайт включает следующие разделы:

- **About (Главная)** - Биография, краткое описание, новости и контакты
- **Research & Publications** - Исследовательские интересы и публикации
- **Education & Work Experience** - Образование и опыт работы (с раскрывающимися деталями)
- **Teaching & Mentoring** - Преподавательская деятельность и менторство

## 🚀 Быстрый Старт

### Для Русскоязычных Пользователей

**ВАЖНО:** Детальные инструкции на английском языке находятся в файле `SETUP_INSTRUCTIONS.md`

### Краткая Инструкция:

1. **Обновите свою информацию:**
   - `_config.yml` - основные настройки (имя уже установлено)
   - `_data/socials.yml` - социальные ссылки и email
   - `_pages/about.md` - страница "О себе"
   - `_pages/publications.md` - исследования и публикации
   - `_pages/experience.md` - образование и опыт работы
   - `_pages/teaching.md` - преподавание

2. **Добавьте контент:**
   - Фото профиля → `assets/img/prof_pic.jpg`
   - CV в формате PDF → `assets/pdf/cv.pdf`
   - Новости → создайте файлы в папке `_news/`

3. **Опубликуйте на GitHub:**
   ```bash
   cd ~/research/web_site_KA
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/lvodoleyl/lvodoleyl.github.io.git
   git branch -M main
   git push -u origin main
   ```

4. **Активируйте GitHub Pages:**
   - Перейдите в настройки репозитория на GitHub
   - Settings → Pages → Source: main branch → Save
   - Подождите 2-5 минут, пока сайт соберётся

## 📁 Основные Файлы

- `_config.yml` - главный конфигурационный файл
- `_pages/` - страницы сайта
- `_news/` - новости и анонсы
- `_data/socials.yml` - ссылки на социальные сети
- `assets/img/` - изображения
- `assets/pdf/` - PDF файлы (CV)
