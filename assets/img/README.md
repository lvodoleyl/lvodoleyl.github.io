# Images Folder

## Profile Picture

Place your profile picture in this folder with the filename **`prof_pic.jpg`**

### Requirements:
- Filename: `prof_pic.jpg` (or update the filename in `_pages/about.md`)
- Recommended size: 400x400 pixels or larger
- Format: JPG, PNG, or JPEG
- Aspect ratio: Square (1:1) works best
- File size: Keep under 500KB for faster loading

## Other Images

You can also add other images to this folder for use in your pages:
- Research project images
- Conference presentations
- Lab photos
- Publication figures

Use them in your markdown files like this:
```markdown
![Description]({{ '/assets/img/your-image.jpg' | relative_url }})
```
