# PDF Files Folder

## CV / Curriculum Vitae

Place your CV PDF file in this folder with the filename **`cv.pdf`**

### Requirements:
- Filename: `cv.pdf` (or update the path in `_data/socials.yml`)
- Format: PDF
- Recommended: Keep file size under 2MB

### Current Status:
⚠️ **CV not yet added** - Add your CV PDF here to enable the download link on your website!

## Other PDFs

You can also store other PDF files here:
- Research papers
- Presentation slides
- Posters
- Technical reports

Link to them in your markdown files like this:
```markdown
[Download PDF]({{ '/assets/pdf/your-file.pdf' | relative_url }})
```
